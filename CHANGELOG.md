# Changelog

## 18.48.2-en.1

- Remove the batch spectrum-report, deuteration and report-signoff tabs and
  their unreferenced backend modules.
- Translate the retained desktop controls, standard messages, generated
  summary schemas and descriptor descriptions into English.
- Read legacy Chinese and earlier English schemas through explicit aliases;
  preserve compound names and original values.
- Add scrolling and wrapped labels where the English layout needs more space.
- Add local Help, a user guide, data-format and methods documentation, a
  synthetic demonstration and release-specific regression tests.
- Retain the 18.48.2 analysis methods, mass constants and image-layout version.
  The later experimental modelling branches are not included.
