# Citing CombiTrace-MS

Record the software name, version (`18.48.2-en.1`), repository commit or
release identifier, and access date in the analysis record. Cite the
associated research article when it is available, together with the exact
archived software release used for the results.

The authors, repository URL and article DOI have not been entered in this
source package. The maintainer should add the actual metadata and, when
appropriate, a `CITATION.cff` file before the public release. No authorship,
institution or DOI is inferred from local file paths or sample records.
