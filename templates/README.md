# Input templates

The templates are blank schemas or generic examples. They do not contain the
study's measured data, verified reaction chemistry or calibrated models.

| File | Use |
|---|---|
| `excel_sheet_abc_template.xlsx` | Two-column formula/mass blocks for each role. |
| `excel_sheet_named_triplet_template.xlsx` | Three-column ID/formula/mass blocks. |
| `ABC_components_with_SMILES_template.xlsx` | Four-column ID/formula/mass/SMILES blocks. Fill and verify mapped structures. |
| `CombiTrace_IE_private_structure_template.xlsx` | Private structure-library schema and explicit reaction-rule settings. Disabled example rule must be checked before enabling. |
| `SMILES_builder_combo_template.csv` | Example mapped connection layout, not a validated synthesis. |
| `LC_gradient_default_v18_26.csv` | Editable gradient example. Replace with the actual method. |
| `negative_ion_panel_template.csv` | Channel review/action schema. Review evidence before including a channel in SUM. |
| `negative_ion_channel_registry.csv` | Candidate channel definitions; inclusion does not establish experimental presence. |
| `external_logIE_template.csv` | Import schema for external IE values. Do not fill with standard concentrations or invented responses. |

A mass cell left blank is not a measured zero. Fill formulas and review the
application's theoretical calculation. Keep instruction sheets out of the
component workbook when all sheets are being enumerated.
